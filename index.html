How it works

  1. A GitHub Action pulls this league from the public Sleeper API every 6 hours.
  2. It writes a compact, fully-readable brief — rosters with real player names, standings, future rookie picks, and top free agents.
  3. The brief also tells the assistant how to query Sleeper directly, so it can pull genuinely live data when your question needs something newer than the snapshot.

  • league.json — same data, structured, for tools and scripts.
